# 🐰 うさうさ研修ツール 6モード統合版

LPIC・IT研修の現場で使う、**単一HTMLの授業支援ツール**です。
ファイル1つをブラウザで開くだけで動きます。インストール不要・ネット接続不要・サーバー不要。

> モットー：面白きこともなき世を面白く

---

## これは何？

研修の「説明30分＋演習30分」を回すための道具を、6つのモードに束ねた1枚のHTMLです。
講師の手元でも、受講生のPCでも、同じファイルがそのまま動きます。

- **配布が楽**：USBやチャットでファイルを1つ渡すだけ
- **壊れにくい**：外部ライブラリに依存しないので、CDNが落ちても動く
- **安全**：個人情報をブラウザに保存しない（localStorage不使用）
- **どこでも動く**：古いブラウザでも動く書き方に統一

---

## 6つのモード

| # | モード | ざっくり言うと |
|---|--------|----------------|
| ① | 講師モード | 配布用ひな形（一次/二次/理解確認/質問シート）をレベル差し込み付きで用意 |
| ② | （統合版の各モード） | 研修運営を支える各種ツール |
| ③ | クイズ大会 | タイマー＋⭕❌判定＋きろく。**受講生が問題も作れる** |
| ④ | PPT構成 | WHY→WHAT→HOW のスライド構成のたたき台を生成 |
| ⑤〜⑥ | （統合版の各モード） | 研修運営を支える各種ツール |

※ モード構成は統合版の仕様に準じます。

## ✨ v5.5.0 の新機能

### 1. タイマー秒数を自由に指定（v5.4.0）

15秒・30秒のプリセットに加えて、**1〜3600秒の任意の秒数**を入力できます。

- 入力欄に数字を入れて「設定」または Enter キーで反映
- 範囲外は自動補正（0以下→1秒、3600超→3600秒）
- 空欄・文字は無視（安全側に倒す）
- 任意秒のときは入力欄が緑にハイライト。プリセットを押すと解除（相互排他）

> 比喩：ラーメンの茹で時間を「かため15秒／ふつう30秒」の2択だけでなく、
> 「この麺は1分10秒」と自由にセットできるタイマーになりました🍜

### 2. 受講生が問題・答え・ヒントを作る（v5.5.0）

クイズモードに「**問題づくり**」を追加。受講生自身が出題者になれます。

- 入力項目：**問題（必須）／答え（必須）／ヒント①②（任意）／作った人（任意・役割表記）**
- 「みんなの問題集」に蓄積され、各問から「▶ 出す」で出題ビューへ
- 出題ビューでは **💡 ヒントを1段ずつ開示** → **👀 答えを見る** の順で進められる
- 出題と同時にタイマーが満タンにリセットされ、そのまま⭕❌判定・きろくへ
- 問題集は **Notion / メモ(txt) / PDF / CSV / Excel** で書き出し可能

> 「教えることが一番の学び」。受講生が問題を作る過程そのものが、理解の確認になります。

## 使い方

1. `_PRO_うさうさ研修ツール_6モード統合版__20260602_.html` をダブルクリック（既定ブラウザで開く）
2. 上部のモード切り替えで使いたいモードを選ぶ
3. クイズで問題を作るときは「✏️ 問題づくり」に入力 →「➕ 問題に追加」
4. 「📚 みんなの問題集」の「▶ 出す」で出題開始

オフラインでそのまま動きます。配布時はファイルをコピーするだけ。

## 技術仕様

| 項目 | 内容 |
|------|------|
| 構成 | 単一HTML（HTML/CSS/JS を1ファイルに同梱） |
| 言語 | バニラ JavaScript（フレームワーク不使用） |
| 外部依存 | なし（CDN・外部スクリプト・Webフォント すべて不使用） |
| データ保存 | メモリ内のみ。localStorage / sessionStorage 不使用 |
| 互換性 | 古いブラウザでも動く構文に統一（`?.` `??` 後読み正規表現は不使用） |
| 出力 | クリップボード / txt / CSV / Excel(XML) / PDF(印刷) |

### 品質保証

- **内蔵セルフテスト 88項目**：ファイルを開くと自動実行され、画面下部に結果表示
- **商用品質テスト（PRO 7フェーズ）**：単体／結合／ホワイトボックス／ブラックボックス／実描画／E2E／監査
- **名前監査**：成果物に同僚・関係者の実名を含めない（役割表記のみ）

## 設計の約束ごと

- 単一HTML・外部依存ゼロ・オフライン動作を崩さない
- 個人情報をブラウザに保存しない
- 成果物に実名を載せない（役割表記で代替）
- 「バグ0 until done」：ツールのバグとテストコードの誤りを区別し、正直に報告する
