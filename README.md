## このページについて

このページは、IT研修現場で使える「うさうさ研修工房」の単一HTMLツール **6モード統合版（v5.0.0／商用レベルテスト合格）** を紹介・配布するためのページです。ブラウザで開くだけで動作し、インストールやインターネット接続は不要です。

上部タブを切り替えると、画面の世界観（背景・配色）ごと6つのモードに変わります。

1. **講師の質問**（新宿ビル風）：講師が受講生から聞き取り、記録を整える
2. **受講生の質問**（小学校風）：受講生がレベル別に「前提・仮説・質問」を組み立てる
3. **30秒クイズ大会**（おもちゃ風）：口頭で出題・回答、講師はタイマーと正誤記録
4. **発表スライド**（プレゼン風）：WHY→WHAT→HOWで発表構成のたたき台を作る
5. **日報・敬語**（オフィス風）：箇条書きを敬語の日報文に整える
6. **認識・理解**（教科書風）：教科書ページ×受講生の言葉そのまま×レベル別で記録

整えた記録は **Notion用コピー／メモ(.txt)／PDF**（クイズは加えて **CSV／Excel**）で保存できます。

## 📝 作成背景

研修現場では、質問対応・小テスト・発表・日報・理解確認といった作業がそれぞれ「その場限り」で流れ、記録が属人化・散逸しがちでした。ツールが分かれていると、開くもの・使い方も増えてしまいます。

そこで、現場で繰り返し使う作業を **1つのファイル・タブ切り替え** にまとめ、迷わず使えて記録が自然に残ることを目指しました。新人（非IT・文系を含む）が萎縮しないよう、「まず出せたら満点」を土台にした足場かけも組み込んでいます。

## 前提

- 研修形態（IT基礎／開発／インフラ／セキュリティ）に依存しない汎用構成です。
- 受講生は **役割表記**（受講生A など）で扱い、個人を特定する氏名は記録しない運用とします。
- 記録に含めるのは事実中心とし、所感は分けて扱います。
- 答えに詰まったときは「確認してお返事いたします」で対応します。

## 本題

### ① 講師の質問（新宿ビル風）

単元・質問者（役割表記）・カテゴリ・緊急度を選び、①やりたいこと〜⑥聞きたいこと、受講生の言葉そのままを記録。結果に「二次対応へ」を選ぶと引継ぎテンプレへの接続を促します。

### ② 受講生の質問（小学校風）

レベル選択（Lv1まず出せたら満点 → Lv4前提・仮説・質問で構造化）に応じてガイドが変化。前提／仮説／質問／答えの使い道を入力。空欄でも「一緒に画面を見てもらえますか？」の案内に変換します。

### ③ 30秒クイズ大会（おもちゃ風）

問題登録は不要。15秒／30秒の切り替えタイマー（実時刻基準で精度が安定）、指名メモ（任意）、⭕❌記録、正解で紙吹雪。結果は正解率つきで保存できます。

### ④ 発表スライド（プレゼン風）

タイトル・つかみ（WHY）・要点（WHAT）・具体例（HOW）・まとめを入力すると、5枚構成のたたき台を生成。出力をPowerPointのアウトライン表示に貼ると、スライドの下書きになります。

### ⑤ 日報・敬語（オフィス風）

「やったこと・気づき・むずかしかったこと・明日の予定」を箇条書きで入れると、敬語の日報文に整形します。語尾を整え、定型の挨拶も補います（下書き補助のため、提出前の内容確認は必要です）。

### ⑥ 認識・理解（教科書風）

教科書ページ・単元に紐づけ、受講生の言葉そのまま・事実・所感（事実と分離）・次の一手（仕組み側）をレベル別に記録します。

## 保存（ダウンロード）機能

| 形式 | 用途 |
|---|---|
| Notion用コピー | Notionに貼ると表（クイズ）やコードブロック（質問）として認識される |
| メモ(.txt) | テキストでそのまま保存。ファイル名に日時を自動付与 |
| PDF | 印刷ダイアログから「PDFとして保存」 |
| CSV（クイズ） | 表計算で開ける。文字化け対策（BOM付与）済み |
| Excel(.xls)（クイズ） | Excelが表として開ける形式（追加ソフト不要） |

すべてブラウザだけで完結し、外部サービスへの送信はありません。

## 共通の設計方針（うさうさ研修工房 作法）

- 単一HTMLファイルで完結（外部リソース読み込みなし、オフライン動作）
- 端末標準フォントのみ使用（CORS回避）
- 状態はすべてメモリ内に保持（ブラウザストレージ不使用、リロードで消える）
- `APP_VER` によるバージョン管理（現在 v5.0.0-hexmode）
- 起動時に自己テストを自動実行し、画面下部に通過状況を表示
- 役割表記前提で、個人を特定する情報は扱わない

## 品質（商用レベルテスト）

配布前に、静的解析と擬似DOM上での実走テストを実施しています。

- 自己テスト：38項目 全通過
- 確認例：6モードそれぞれの出力、クイズ集計・タイマー精度、PPTの5枚構成、日報の敬語化、認識記録の引用処理、CSV/Excelエスケープ、入力サニタイズ、HTMLエスケープ
- 構造・構文：DOM構造の収支一致、CSS変数クリーン、JS構文OK

### 実機で確認推奨

- PDF出力はポップアップを使うため、ブラウザのポップアップブロックが有効だと止まります（その旨を通知します）。
- クリップボードコピー・バイブレーションは端末（iOS Safari／Android Chrome）での最終確認を推奨します。
- 発表スライドは構成のたたき台です。実際の .pptx が必要な場合は別途生成します。
- 日報の敬語整形は下書き補助です。提出前に内容を確認してください。
